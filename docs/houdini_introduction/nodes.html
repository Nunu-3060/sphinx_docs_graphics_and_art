ノードとネットワーク

Houdini の作業は、全てノードのネットワークの上で行う。この章では、ネットワークの種類、ノードのつなぎ方、フラグ、ノードが計算される仕組み（クック）を説明する。

ネットワークの階層とコンテキスト

Houdini のシーンは、ファイルシステムのような木構造になっている。最上位（/）の下に、扱うデータの種類ごとのネットワークがあり、ノードの中にさらにネットワークを持つものもある。ノードの場所は /obj/table/OUT のようなパスで表す。ファイルシステムと同じく、.. は 1 つ上の階層を表す。

ネットワークが扱うデータの種類をコンテキストと呼ぶ。コンテキストによって、作れるノードの種類が決まっている。各コンテキストのノードは、OBJ、SOP のような略称で呼ばれる。

オブジェクトとジオメトリ

形状を作るには、まず /obj に Geometry ノード（オブジェクト）を作り、その中に入って SOP のノードを並べる。

  • オブジェクト（/obj のノード）は、シーンの中の 1 個の物を表す。位置、回転、大きさ（オブジェクトの変換）と、表示するかどうかを持つ。

  • ジオメトリ（Geometry ノードの中の SOP のネットワーク）は、その物の形を表す。SOP のネットワークのうち、ディスプレイフラグ（後述）を立てたノードの出力が、オブジェクトの形になる。

例えば机と椅子を作るなら、/obj に table と chair の 2 個の Geometry ノードを作り、それぞれの中で形を作るのが一般的である。

ノードの作成と接続

ネットワークエディターで Tab を押すと Tab メニューが開く。ノードの名前（例えば box）を入力して Enter を押し、ネットワークエディターの中をクリックすると、その位置にノードが作られる。ノードの名前は、作った後に名前の部分をダブルクリックして変えられる。

ノードには 0 個以上の入力と、1 個以上の出力がある。Box ノードのように形状を新しく作るノードは入力を持たない。Transform ノードのように形状を加工するノードは、入力に受け取った形状を加工して出力する。Merge ノードや Boolean ノードのように、複数の入力を受け取るノードもある。入力にワイヤーをつなぐと、上のノードの出力が下のノードに渡される。

1 個のノードの出力を、複数のノードの入力につなぐこともできる。この場合、同じ結果が分岐してそれぞれのノードに渡される。

フラグ

SOP のノードの左右の端には、フラグ（flag）と呼ばれるスイッチがある。クリックするか、ノードを選んでキーを押すと切り替わる。

クックと依存関係

ノードが処理を実行して結果を作ることを、クック（cook）と呼ぶ。Houdini は、全てのノードを常に計算しているわけではない。ビューポートに表示するなど、結果が必要になったノードだけを、その上流のノードから順にクックする。クックした結果は保存され、次に必要になったときに再利用される。

あるノードのパラメーターを変えると、そのノードと、そこから下流にある全てのノードの結果が古くなった（dirty）とみなされる。結果が再び必要になったときに、古くなったノードだけがクックし直される（図 9）。この仕組みは、ビルドツールの make が、変更されたファイルに依存するものだけを作り直すのに似ている。

図 9 では、lift_top のパラメーターを変えている。top と、脚を作る 3 個のノードはクックし直されず、保存された結果が使われる。

非破壊編集

ネットワークでは、上流のノードのパラメーターをいつでも変更できる。変更は下流の全てのノードに自動的に反映される。途中にノードを差し込むことも、ノードを取り除くこともできる。このように、作った結果を壊さずに途中の手順を編集できることを、非破壊編集と呼ぶ。

ただし、下流のノードが上流の結果の「何番目の点」のような番号に頼っている場合、上流の変更で点の数や順序が変わると、下流の結果が意図しないものになる。番号の代わりに、グループやアトリビュート（ジオメトリとアトリビュート）で処理の対象を指定すると、変更に強いネットワークになる。

Null ノードと OUT

Null ノードは、入力をそのまま出力するだけのノードである。何もしないが、ネットワークの最後に OUT という名前の Null ノードを置く習慣がある。

  • ネットワークの出口がひと目で分かる。

  • 他のネットワークから /obj/table/OUT のようなパスで結果を参照するとき、途中のノードを追加したり削除したりしても、参照先を変えずに済む。

本資料の作例でも、全てのネットワークの最後に OUT を置く。
