用語集

本資料で使った主な用語をまとめる。英字の用語をアルファベット順に、その後に日本語の用語を五十音順に並べた。括弧の中は、詳しく説明している章である。

英字

Apprentice

Houdini の無償の非商用版。保存するファイルの形式、レンダリングの解像度などに制限がある。（Houdini とは）

Attribute Wrangle

VEX のコードを、ジオメトリの要素ごとに実行する SOP。（VEX 入門）

Copy to Points

形状を、別の形状の各ポイントにコピーする SOP。ポイントの pscale、scale、orient などのアトリビュートで、コピーの大きさや向きを変えられる。（はじめてのモデリング、プロシージャルモデリングの実践）

DAG

閉路の無い有向グラフ（Directed Acyclic Graph）。Houdini のネットワークはこの形になる。（Houdini とは）

DOP

シミュレーションを行うノードとネットワーク。Dynamics OPerator の略。（ノードとネットワーク、シミュレーション入門）

For-Each ループ

Block Begin ノードと Block End ノードの間のノードを、要素ごとに繰り返し実行する仕組み。（プロシージャルモデリングの実践）

HDA

Houdini Digital Asset の略。デジタルアセット を参照。

hip ファイル

Houdini のシーンファイル。Apprentice では拡張子が .hipnc になる。（画面と基本操作）

HOM

Houdini Object Model の略。Houdini の Python API（hou モジュール）のこと。（Python による操作）

Hscript

Houdini 独自の式言語とコマンド言語。パラメーターの式は、既定では Hscript で書く。（パラメーターとエクスプレッション）

hython

Houdini に付属する Python のインタープリター。画面を開かずに Houdini の機能を使える。（Python による操作）

Karma

Houdini に付属するレンダラー。CPU で計算する Karma CPU と、GPU も使える Karma XPU がある。（マテリアルとレンダリング）

LOP

USD のステージを組み立てるノードとネットワーク。Solaris とも呼ぶ。（ノードとネットワーク、マテリアルとレンダリング）

MaterialX

マテリアルを記述するためのオープンな形式。Karma のマテリアルの標準である。（マテリアルとレンダリング）

Null ノード

入力をそのまま出力するノード。ネットワークの出口の目印（OUT）として使う。（ノードとネットワーク）

OBJ

シーンに置く物（オブジェクト）を扱うノードとネットワーク。/obj にある。（ノードとネットワーク）

Python SOP

Python のコードでジオメトリを作ったり変更したりする SOP。（Python による操作）

ROP

レンダリングやファイルの書き出しを行うノード。Render OPerator の略。（ノードとネットワーク）

Solaris

Houdini で、USD を使ってレンダリングのためのシーンを組む環境。LOP を参照。（マテリアルとレンダリング）

SOP

ジオメトリを作り、加工するノードとネットワーク。Surface OPerator の略。（ノードとネットワーク）

USD

Universal Scene Description の略。3DCG のシーン全体を記述する形式。（マテリアルとレンダリング）

UV 座標

形状の表面に画像を貼るための、2 次元の座標。（3DCG の基礎知識）

VEX

ジオメトリの要素ごとの処理を並列に実行する、C 言語に似た言語。（VEX 入門）

VOP

VEX のプログラムをノードで組み立てる仕組み。マテリアルの定義にも使う。（VEX 入門）

日本語

アトリビュート

ジオメトリの要素ごとに持たせる名前付きのデータ。位置（P）や色（Cd）もアトリビュートである。（ジオメトリとアトリビュート）

インスタンス

デジタルアセットの定義から作った個々のノード。（デジタルアセット）

エクスプレッション

パラメーターに入力する式。値が必要になるたびに計算される。（パラメーターとエクスプレッション）

オブジェクト

/obj に置く、シーンの中の 1 個の物。位置や表示の有無を持つ。（ノードとネットワーク）

キーフレーム

あるフレームでのパラメーターの値を指定したもの。間のフレームの値は補間される。（パラメーターとエクスプレッション）

キャッシュ

計算の結果を保存しておき、再利用すること。また、保存したファイル。（ノードとネットワーク、シミュレーション入門）

クック

ノードが処理を実行して結果を作ること。（ノードとネットワーク）

グループ

ジオメトリの要素に付ける名前付きの集合。ノードの処理の対象を絞るのに使う。（ジオメトリとアトリビュート）

コンテキスト

ネットワークが扱うデータの種類。SOP、LOP、DOP などがある。（ノードとネットワーク）

シェルフツール

シェルフに置くボタン。押すとスクリプトが実行される。（画面と基本操作、Python による操作）

ジオメトリ

形状のデータ。ポイント、バーテックス、プリミティブ、ディテールと、それらのアトリビュートからなる。（ジオメトリとアトリビュート）

シミュレーション

物理法則に従って、前のフレームの状態から次のフレームの状態を計算すること。（シミュレーション入門）

ステージ

USD のシーン。プリムの木構造である。（マテリアルとレンダリング）

スペアパラメーター

ノードに後から追加したパラメーター。（VEX 入門）

タプル

パラメーターの、複数の成分をまとめたもの。例えば t は tx、ty、tz のタプルである。（パラメーターとエクスプレッション）

チャンネル参照

ch() 関数で、他のパラメーターの値を参照すること。（パラメーターとエクスプレッション）

ディスプレイフラグ

ビューポートに表示するノードを示すフラグ。（ノードとネットワーク）

ディテール

ジオメトリ全体を表す要素。ジオメトリに 1 つだけある。（ジオメトリとアトリビュート）

デジタルアセット

ネットワークを 1 個の新しい種類のノードとしてまとめたもの。HDA とも呼ぶ。（デジタルアセット）

ネットワーク

ノードをワイヤーでつないだもの。（ノードとネットワーク）

ノード

1 つの処理を表す部品。入力を受け取り、パラメーターに従って処理し、結果を出力する。（ノードとネットワーク）

バーテックス

プリミティブの角。プリミティブがどのポイントを使うかを表す。（ジオメトリとアトリビュート）

バイパスフラグ

ノードの処理を無効にし、入力をそのまま出力させるフラグ。（ノードとネットワーク）

パラメーター

ノードの動作を決める値。（画面と基本操作、パラメーターとエクスプレッション）

非破壊編集

作った結果を壊さずに、途中の手順を編集できること。（ノードとネットワーク）

フラグ

ノードの左右の端にある、ノードの状態を切り替えるスイッチ。（ノードとネットワーク）

プリミティブ

ポイントをつないで作る形状の単位。ポリゴン、曲線、球などがある。（ジオメトリとアトリビュート）

プリム

USD のステージの要素。/table のようなパスを持つ。（マテリアルとレンダリング）

プロシージャル

形状を直接編集するのではなく、形状を作る手順を組み立てて形状を作る方法。（Houdini とは）

ポイント

空間の中の位置を表す要素。（ジオメトリとアトリビュート）

法線

面がどちらを向いているかを表す、長さ 1 のベクトル。（3DCG の基礎知識）

マテリアル

物の表面の質感（色、粗さ、金属らしさなど）を表すもの。（3DCG の基礎知識、マテリアルとレンダリング）

レイトレーシング

カメラから光線を飛ばし、物に当たって反射する光をたどって画像を計算する方法。（3DCG の基礎知識）

レンダリング

シーンの情報から画像を計算する処理。（3DCG の基礎知識、マテリアルとレンダリング）

ローカル変数

ノードが要素を 1 つずつ処理するときに、処理中の要素の値を表す変数。$TY など。（ジオメトリとアトリビュート）
