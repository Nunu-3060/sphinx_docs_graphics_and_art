はじめに

本資料の目的

Houdini は、映画の視覚効果（VFX）やゲーム開発などで使われている 3DCG ソフトウェアである。他の多くの 3DCG ソフトウェアでは、画面上の形状をマウスで直接編集してモデルを作る。これに対して Houdini では、「箱を作る」「穴を開ける」「点の位置にコピーする」といった処理を表すノードをつないで、形状を作る手順そのものを組み立てる。この作り方をプロシージャル（procedural、手続き的）と呼ぶ。

手順を組み立てるという考え方は、プログラムを書くことによく似ている。そのため Houdini は、モデリングの経験が無くても、プログラミングの経験があるエンジニアにとって入りやすいソフトウェアである。本資料は、この強みを活かして、Houdini の基本的な考え方と操作を短い時間で身に付けることを目的とする。

対象読者と前提知識

本資料は、次のような読者を想定している。

  • 3DCG のモデリングやアニメーションの経験は無い。

  • Python の基本的な文法（変数、関数、リスト、辞書、for 文）を理解している。

  • コマンドラインでスクリプトを実行したことがある。

3DCG の用語や数学の知識は前提としない。必要な知識は 3DCG の基礎知識 で説明する。C 言語に似た文法（波かっこ、セミコロン、型宣言）を見たことがあると、VEX 入門 を読みやすい。

サンプルコードの使い方

本資料のサンプルコードは、サンプルコード一覧 からまとめてダウンロードできる。展開すると examples ディレクトリができる。以降の説明では、C:\houdini_intro\examples に置いたものとする。

サンプルコードの多くは、Houdini の中にノードのネットワークを組み立てる Python スクリプトである。本文の操作手順で作るネットワークと同じものを、スクリプトで一度に作れる。手順の途中で分からなくなったときに、完成形と見比べるのに使う。

Houdini の画面から実行する

Windows ‣ Python Shell で Python Shell を開き、次のように入力する。build_table の部分は、実行したいスクリプトの名前（拡張子 .py を除いたもの）に置き換える。

1import sys
2sys.path.append(r"C:\houdini_intro\examples")
3import build_table
4build_table.build()

1 行目と 2 行目は、Python がモジュールを探す場所に examples ディレクトリを追加している。3 行目でスクリプトをモジュールとして読み込み、4 行目でネットワークを組み立てる関数を呼んでいる。Python は一度読み込んだモジュールを再び読み込まないので、スクリプトを書き換えた後は、import importlib を実行してから importlib.reload(build_table) で読み込み直す。

hython から実行する

hython は、Houdini に付属する Python のインタープリターである。画面を開かずに Houdini の機能を使える（Python による操作 を参照）。コマンドプロンプトで次のように実行すると、ネットワークを組み立てて結果を表示し、シーンファイル table.hipnc に保存する。

1cd C:\houdini_intro\examples
2"C:\Program Files\Side Effects Software\Houdini 22.0.466\bin\hython.exe" build_table.py table.hipnc

本資料の執筆時に、hython は Apprentice のライセンスでも動作することを確認した。

注釈

サンプルコードと同じディレクトリに、Houdini が内部で使う Python モジュールと同じ名前のファイル（例えば dbg.py）を置かない。Houdini がそのファイルを誤って読み込み、一部の機能が動かなくなることがある（Python による操作 の「モジュールの名前に注意する」を参照）。
