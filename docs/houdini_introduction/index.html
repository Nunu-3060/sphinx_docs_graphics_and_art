Houdini 入門

本資料は、3DCG ソフトウェア Houdini の使い方を、モデリングの経験は無いがプログラミングの経験はあるエンジニア向けにまとめたものである。Houdini の最大の特徴である「プロシージャル」な作り方を軸に、3DCG の基礎知識、画面の操作、ノードによるモデリング、アトリビュート、VEX、Python による自動化、デジタルアセット、レンダリング、シミュレーションまでを、手を動かしながら学ぶ。

各章の作例は、Houdini の操作手順と、同じネットワークを組み立てる Python スクリプトの両方で示す。スクリプトは無償版の Houdini Apprentice で動作を確認している。
